## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge, etc.)
- No additional installation required

### Running Locally

1. Clone the repository:
```bash
git clone https://github.com/Josh03-spec/portfolio-website.git
cd portfolio-website
```

2. Open the website in your browser:
   - Simply double-click `index.html` file, or
   - Open it with your preferred web server

3. For a better development experience, you can use a local server:
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (if you have http-server installed)
http-server
```

Then visit `http://localhost:8000` in your browser.

## 🌐 Deployment

This static website can be easily deployed to:
- **GitHub Pages** - Free hosting directly from this repository
- **Netlify** - Automatic deployments from git
- **Vercel** - Fast, optimized static hosting
- **Any web hosting provider** - Simply upload the files via FTP

### Deploy to GitHub Pages

1. Go to repository Settings → Pages
2. Select "Deploy from a branch"
3. Choose `main` branch and save
4. Your site will be live at: `https://Josh03-spec.github.io/portfolio-website/`
